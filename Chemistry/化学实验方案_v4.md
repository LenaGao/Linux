## 一、电解系统——本版重点解决

### 1.1 设备参数与关键发现

| 参数 | 实测/说明书 |
| :--- | :---: |
| 电极间距 | **5.0 cm** |
| 电极长度 | **2.5 cm** |

| 说明书建议电压 | **12–18 V DC** |
| 说明书建议电解质 | 稀硫酸 或 稀 NaOH |

### 1.2 故障诊断：为什么氧气看不见

**实验现象：** 4.5V 电池 + 1% NaHCO₃ → 阴极剧烈产氢，阳极完全无气泡，两极均有白色沉积（阳极更明显）。

**原因分析（三重叠加）：**

**① 电压严重不足**——4.5 V 只有设计值的 **1/4**

**② 电解质过稀**——1% NaHCO₃ 电导率极低

按欧姆定律估算回路电阻：

$$R = \rho \times \frac{L}{A} \approx \frac{5.0}{0.008 \times 5} = 125\ \Omega$$

$$I_{4.5V} = \frac{4.5 - 2}{125} \approx 0.036\ \text{A（仅 36 mA）}$$

对应产氧速率：

$$V_{\text{O}_2} = \frac{0.036}{96485 \times 4} \times 24450 \times 60 = 0.14\ \text{mL/min}$$

**每分钟 0.14 mL——而阳极室溶液能溶解掉好几毫升，永远看不见气泡。**

**③ 氢氧不对称**——氧气"藏起来"的双重原因

| 气体 | 每摩尔电子产量 | 25°C 溶解度 | 达到过饱和所需电量 |
| :--- | :---: | :---: | :---: |
| H₂ | 0.5 mol | 19.6 mL/L | 基准 |
| O₂ | 0.25 mol | 30.6 mL/L | **约 3 倍** |

氢气成核速度是氧气的约 3 倍。低电流时，氢气已剧烈冒泡，氧气还在安静溶解。

**④ 白色沉积——绝缘层的恶性循环**

| 电极 | 沉积成因 | 化学式 |
| :--- | :---: | :---: |
| 阴极（少量，正常） | 局部 OH⁻ 升高，拉出水中 Ca²⁺/Mg²⁺ | Ca²⁺ + CO₃²⁻ → CaCO₃↓ |
| **阳极（明显，异常）** | 结垢 + 可能的电极氧化 | CaCO₃ 或金属氢氧化物 |

沉积层绝缘 → 有效面积下降 → 电阻升高 → 电流更小 → 沉积更快。

> **顺带的教学实验**：刮下白色物滴食醋——剧烈起泡 = CaCO₃（硬水结垢，换蒸馏水解决）；溶解不起泡 = 金属氢氧化物（电极腐蚀）。碳酸盐检验顺手完成设备诊断。

### 1.3 解决方案与工作参数

**关键认识：电解质浓度比电压更重要。**

不同浓度下达到目标电流 0.5 A 所需电压：

| 电解质 | 估算回路电阻 | 达 0.5 A 所需电压 | 可行性 |
| :--- | :---: | :---: | :---: |
| 1% NaHCO₃ | ~125 Ω | > 24 V | ❌ 达不到 |
| 2% Na₂CO₃ | ~60 Ω | ~32 V | ❌ 达不到 |
| **5% Na₂CO₃** | **~25 Ω** | **~14 V** | ✅ **推荐** |
| 10% Na₂CO₃ | ~15 Ω | ~9.5 V | ✅ 可用 |

**最终推荐配置：**

```
电解质：5% Na₂CO₃（洗衣苏打），50 g 溶于 1 L 蒸馏水
电压：  从 6V 起调，预期工作点 12–15V
目标：  电流 0.3–0.8 A
```

**为什么用洗衣苏打而非 NaOH：**

| 项目 | Na₂CO₃ | NaOH |
| :--- | :---: | :---: |
| pH | 11.5（足够保护电极钝化膜） | 13+ |
| 安全性 | 误触仅轻微刺激 | 不可逆眼损伤 |
| 成本 | 一元店 $1.25 | $4.50 |
| 玻璃侵蚀 | 无 | 长期侵蚀刻度 |
| 学生可否操作 | ✅ 可以 | ❌ 需教师操作 |

⚠️ **不要用 NaCl**：Cl⁻ 击穿电极钝化膜 + 阳极产氯气。
⚠️ **不要用 Na₂SO₃**：亚硫酸根是还原剂，在阳极优先被氧化，**阳极不出氧**。若要中性电解质，用 Na₂SO₄。

### 1.4 电源方案

**ALITOVE 3–24V 可调电源（连续可调，无限流）**

**无限流不是问题**——用电压本身当限流手段。核心规则一条：

> **任何改变回路条件的操作（换液、调整电极、缩短间距）之前，先把电压旋钮转回最低。**

| 风险场景 | 对策 |
| :--- | :---: |
| 换更浓电解质 | 先调回 6V 再换液 |
| 溶液升温致电流爬升 | 运行超 10 分钟摸外壳，烫手即断电 |
| 电极意外接触短路 | 断电操作 |

**万用表串联在回路中**——LCD 只显示电压，而电流才是决定产气速率的量。

### 1.5 标准操作流程

```
① 醋泡除白色沉积 20 分钟，软刷清洗，蒸馏水冲净
② 配制 5% Na₂CO₃（蒸馏水，避免硬水结垢）
③ 电压调至最低 3V，接线，万用表串联
④ 通电，每升 2V 记录一次电流
⑤ 电流达 0.5A 停止升压，记下工作电压
⑥ 空跑 10 分钟使溶液被 O₂ 饱和
⑦ 排空重新收集，正式实验
```

**第 ④ 步的数据本身就是分解电压实验**（见 3.1）。

**第 ⑥ 步不可省略**——否则前几分钟氧气全用于溶解，比值会偏离到 2.2:1 以上；饱和后能稳定在 1.97:1。

### 2.2 干电池拆解——三合一化学品

超重型（Heavy Duty）干电池即锌碳电池：锌兼作外壳与负极，MnO₂/碳混合物包裹中心石墨棒。

⚠️ **必须买 Heavy Duty（锌碳），不要碱性电池（Alkaline）**——后者锌是粉末状且含 KOH 强碱，拆解危险且无完整锌壳。

| 部件 | 产物 | 用途 |
| :--- | :---: | :---: |
| 外壳 | **金属锌 Zn** | 制氢最佳金属、原电池、置换 |
| 黑色糊状物 | **MnO₂** | H₂O₂ 分解催化剂 |
| 中心棒 | **石墨 C** | 氯碱电解惰性阳极 |

**拆解步骤：**

1. 钳子剥去外层包皮
2. 小刀沿顶部密封圈划开，取出中心石墨棒
3. 刮下 MnO₂ 糊状物，**保持湿润**
4. 剪开锌壳展平，清水冲洗、砂纸打磨
5. 石墨棒刷洗晾干

⚠️ **MnO₂ 干粉尘有害，绝不可干磨**；用新电池（废电池已漏液、锌壳变薄）；锌壳边缘锋利需打磨；全程手套护目镜。

### 2.3 锌补全了金属活动性序列

之前只有 Al、Fe、Cu，缺锌。补上后完整：

$$\text{Al} > \text{Zn} > \text{Fe} > (\text{H}) > \text{Cu}$$

**为什么锌是制氢最佳金属：**

| 金属 | 与稀盐酸反应 | 评价 |
| :--- | :---: | :---: |
| Al | 氧化膜钝化，起始慢后突然剧烈 | 不稳定 |
| **Zn** | **速率适中稳定，气泡均匀** | ✅ 最佳 |
| Fe | 较慢，Fe²⁺ 使溶液变绿污染视野 | 可用 |
| Cu | 不反应 | 对照组 |

### 2.4 MnO₂ 让氧气问题彻底解决

$$2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2\uparrow$$

3% 双氧水 500 mL ≈ 0.44 mol → **约 5 L 氧气**，几分钟放完。

| 制氧方案 | 250 mL 耗时 | 成本 |
| :--- | :---: | :---: |
| 电解（0.5 A） | 48 分钟 | 0，但同时产 500 mL H₂ 需排放 |
| **MnO₂ + H₂O₂** | **约 30 秒** | **约 $0.10** |

**催化剂概念的完整证明：**

1. 单独加热 H₂O₂ → 缓慢分解
2. 加 MnO₂ → 剧烈放氧
3. 反应后过滤回收 MnO₂，**称重不变**
4. 回收的 MnO₂ 再次使用 → 依然有效

**第 3、4 步是催化剂定义的直接证明**，其他材料很难做得这么干净。

**电解的价值现在只剩 2:1 定量验证**——但那恰恰是最核心的实验。

## 三、实验体系

### 3.1 分解电压测定 ★ 新增，可调电源专属

从 0 V 缓慢升压，记录电流：

| 电压区间 | 电流 | 现象 |
| :--- | :---: | :---: |
| < 1.23 V | ≈ 0 | 无气泡 |
| 1.23–1.8 V | 极小 | 偶见气泡 |
| **> 1.8–2.0 V** | **明显上升** | **持续产气** |

**电流突然起飞的拐点就是分解电压**（理论 1.23 V + 过电位）。固定电压电源做不出这个实验。

**延伸**：固定电解质改变电压画 I–V 曲线；固定电压换电解质比较电导率。学生可自行发现**法拉第定律**——产气量正比于电量，与电压无直接关系。

### 3.2 水的组成 2:1 定量验证（核心实验）

$$2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{H}_2\uparrow + \text{O}_2\uparrow$$

**建议做法**：每 2 分钟同时读两管体积，作 V(H₂)–V(O₂) 图，从**斜率**得结论，而非单点比值。

实测常得 1.9:1——O₂ 溶解度是 H₂ 的 1.6 倍。**这个偏差不要掩盖**，正好讲系统误差。空跑饱和后可达 1.97:1。

### 3.3 三大气体（全部低成本）

| 气体 | 最优制法 | 成本 | 检验 |
| :--- | :---: | :---: | :---: |
| **O₂** | H₂O₂ + MnO₂（电池） | $1.25 | 带火星木条复燃 |
| **H₂** | Zn（电池壳）+ 稀盐酸 | $1.25 + 酸 | 验纯、爆鸣 |
| **CO₂** | 蛋壳/小苏打 + 醋 | ≈0 | 自制石灰水变浑浊 |

**三种气体原料合计不到 $3**，且氧气和氢气核心材料来自同一节电池。

### 3.4 金属活动性完整实验

材料：铝箔、锌壳、钢丝棉、铜丝 + 稀盐酸

| 金属 | 现象 | 结论 |
| :--- | :---: | :---: |
| Al | 起始慢（氧化膜），后剧烈 | 最活泼但钝化 |
| Zn | 稳定持续产气 | 活泼 |
| Fe | 缓慢产气，溶液变浅绿 | 中等 |
| Cu | 无反应 | 氢之后 |

**免费的经典实验——1982年后美分硬币**

美国 1982 年后 1 美分为**锌芯（97.5%）+ 铜壳（2.5%）**：

1. 锉刀在边缘锉出小缺口
2. 浸入稀盐酸数小时
3. 锌溶解产氢，**留下完整铜壳**

**同一枚硬币上一种金属溶解、另一种不溶**——金属活动性最直观的证据。

### 3.5 活性炭吸附实验 ★ 新增

| 实验 | 现象 | 教学点 |
| :--- | :---: | :---: |
| 红色饮料脱色 | 鲜红→无色 | 吸附作用 |
| 红糖水脱色 | 棕→浅黄 | 制糖工业原理 |
| 碘酒脱色 | 棕→淡黄 | 配淀粉检验残留 |
| 不同炭量梯度 | 脱色程度不同 | 吸附容量、饱和 |

**吸附 vs 吸收的区别**、**比表面积的意义**（1 g 活性炭表面积≈两个网球场）用此最直观。

⚠️ 电池里的碳黑（50–100 m²/g，导电用）**不能替代活性炭**（800–1500 m²/g），前者未经活化造孔。

### 3.6 电化学完整链条

```
拆电池（测 1.5V）→ 认识原电池结构
        ↓
自制锌铜原电池 → 点亮 LED
        ↓
分解电压测定（可调电源）
        ↓
电解水 2:1 定量
        ↓
氯碱演示（石墨阳极 + 氯气试纸）
        ↓
电镀铜（铁丝作阴极）
```

**氯碱演示配置**：

| 位置 | 电极 | 现象 | 反应 |
| :--- | :---: | :---: | :---: |
| 阳极 | **石墨**（电池取出） | 氯气试纸变蓝 | 2Cl⁻ − 2e⁻ → Cl₂↑ |
| 阴极 | 原装电极 | pH 试纸变深蓝 | 2H₂O + 2e⁻ → H₂↑ + 2OH⁻ |

⚠️ 小电流、短时间、开窗，试纸变色即停。

### 3.7 定量化学（坩埚 + 恒重法）

| 实验 | 反应 | 理论失重 |
| :--- | :---: | :---: |
| 小苏打分解 | 2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑ | **36.9%** |
| 泻盐失水 | MgSO₄·7H₂O → MgSO₄ | **51.2%** |
| 蛋壳煅烧 | CaCO₃ → CaO + CO₂↑ | 44.0%（实测46–48%） |
| 硫酸铜结晶水 | CuSO₄·5H₂O → CuSO₄ | 36.1%，反推 n=5 |

**恒重法**：空坩埚恒重 → 加样称重 → 加热至无气体 → 冷却称重 → 再加热10分钟再称，直到两次差 < 0.02 g。

**蛋壳实测偏高**是因含约 3.5% 有机基质（壳膜蛋白）一并烧掉——正好讲**样品纯度与系统误差**。

⚠️ 硫酸铜超 650°C 分解为黑色 CuO，必须小火 + 石棉网，控制在 250–300°C。

### 3.8 蛋壳煅烧——钳夹直烧法

**去掉坩埚热负载，1–3 分钟即可**（坩埚 15 g 瓷本身吃掉 10.5 kJ，比样品还多）：

| 环节 | 要求 |
| :--- | :---: |
| 火焰位置 | **蓝色内锥尖端上方 1–2 cm**（1200–1300°C） |
| 片子大小 | 指甲盖大小（约 1 cm） |
| 钳口散热 | 夹边缘一角，中途换位；批量用不锈钢网勺 |
| 预处理 | 洗去内膜、**彻底晾干**（湿蛋壳爆裂弹射） |

**判据**：滴水明显放热、嘶声、开裂粉化；或加水测 pH ≈ 12.4。

| 目的 | 方式 |
| :--- | :---: |
| 快速演示、制石灰水 | 钳子直夹 |
| 定量测失重率 | 坩埚（需称重） |
| 批量制 CaO | 网勺 |

### 3.9 自制 NaOH——苛化法（教学叙事）

$$\text{Ca(OH)}_2 + \text{Na}_2\text{CO}_3 \rightarrow \text{CaCO}_3\downarrow + 2\text{NaOH}$$

| 物质 | Ksp | 溶解度 |
| :--- | :---: | :---: |
| Ca(OH)₂ | 5.5×10⁻⁶ | 1.7 g/L |
| CaCO₃ | 3.3×10⁻⁹ | 0.013 g/L |

**关键：用石灰乳（悬浮液）而非澄清石灰水。** Ca(OH)₂ 溶解度仅 1.7 g/L，澄清液量远不够；固体不断溶解补充，反应才能进行到底。

**纯度检验**：滴食醋于滤液，有气泡=Na₂CO₃ 未反应完；无气泡=苛化完全。

**同离子效应细节**：当 NaOH 达 0.5 M 时

$$[\text{Ca}^{2+}] = \frac{5.5\times10^{-6}}{0.5^2} = 2.2\times10^{-5}\ \text{M}$$

**产物自己的 OH⁻ 把杂质压下去了——碱越浓越干净。**

> 虽然 $4.50 可买瓶装 NaOH，但这条路线的教学价值（Leblanc 制碱法后半段、石灰循环、循环经济）无可替代。**建议保留为工艺演示，日常实验用瓶装碱。**

### 3.10 pH 试纸测遍所有材料

| 物质 | pH | 教学要点 |
| :--- | :---: | :---: |
| 食醋 | 2.4 | 弱酸 |
| 碳酸水 | 5.5 | CO₂ 溶于水 |
| 味精水 | 6.8–7.2 | 略偏中性 |
| 食盐水/蔗糖水 | 7.0 | 不水解/非电解质 |
| 小苏打水 | 8.3 | 弱碱性 |
| **洗衣苏打** | **11.5** | 明显强于小苏打 |
| 石灰水（自制） | 12.4 | 强碱 |

**缓冲现象**：醋 + 小苏打逐滴中和，pH 先在 4.5 附近赖着不动一大段再突然跳升。**这就是血液维持 pH 7.4 的机制。**

## 五、安全总则

### 🔴 一级：不可逆伤害或致命

| 项目 | 风险 | 措施 |
| :--- | :---: | :---: |
| **酸 + 漂白水** | 生成 Cl₂，家庭最常见致死事故 | **绝不演示**，仅讲原理；两者分开存放 |
| **NaOH（通渠剂）** | 100% 纯碱，对眼不可逆 | 护目镜全程；皮肤滑腻感=正在溶解，冲水 15 分钟 |
| **氢氧混合气** | 2:1 恰是爆炸最强比例，极限 4–75% | 两极产物分开收集；点燃前必须验纯 |
| **MnO₂ 干粉尘** | 吸入有害，神经毒性 | **绝不干磨**，保持湿润 |
| **硫酸铜** | 口服致死量 10–20 g | 必须上锁；废液不可入下水道 |

> 备稀醋仅用于台面清理。**皮肤沾碱只能用水冲**——中和放热会加重损伤。

### 🟠 二级：需严格控制

- **电解电源**：无限流，改变回路条件前先调回最低电压；运行超 10 分钟摸外壳测温
- **电池拆解**：用新电池；锌壳边缘锋利；电解质弱酸性
- **浓盐酸**：户外稀释；**酸入水，绝不水入酸**；塑料容器
- **氯气演示**：小电流短时间，开窗，试纸变色即停
- **坩埚骤冷**：必须自然冷却，勿碰冷台面或水
- **铁丝/钢丝棉燃烧**：集气瓶底必铺细沙
- **镀锌铁丝**：锌沸点 907°C，预热挥发有毒，须先打磨
- **蛋壳爆裂**：未干透会弹射，护目镜 + 侧向 30 cm 观察

### 🟡 三级：常规注意

- 酒精、异丙醇易燃，与明火分开
- pH 试纸不可测非水体系
- 钢丝棉极易燃，远离火源存放

### 废液处理

| 废液 | 处理 |
| :--- | :---: |
| 含 Cu²⁺ | 加 NaOH → Cu(OH)₂↓，过滤，固废 |
| 含 Zn²⁺ | 同上 → Zn(OH)₂↓ |
| 酸碱 | 相互中和至 pH 6–8 后大量水稀释 |
| MnO₂ | 回收重复使用（催化剂不消耗） |
