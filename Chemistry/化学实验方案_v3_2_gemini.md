## 第二部分：六大核心 AP 级化学实验 SOP

### 实验一：催化动力学与纯氧制备 (

```rendered
H2O2
```

分解)

* **化学原理**：

  ```rendered
  2H2O2MnO22H2O+O2↑
  ```
* **所需材料**：3% 双氧水、电池拆出的

  ```rendered
  MnO2
  ```

  黑粉。
* **设备**：锥形瓶、导气管、集气瓶（底部装2cm水用于后续燃烧）。
* **SOP**：将

  ```rendered
  MnO2
  ```

  粉末投入

  ```rendered
  H2O2
  ```

  中，利用排水集气法收集纯氧。
* **教学点**：非均相催化剂降低活化能（Activation Energy）。

### 实验二：纯氧燃烧与热力学传导控制 (

```rendered
Fe+O2
```

)

* **化学原理**：

  ```rendered
  3Fe+2O2→Fe3O4
  ```

  (尖晶石结构)
* **所需材料**：纯氧集气瓶（底必有水/沙）、**#0 号钢丝绒**、**95% 乙醇**。
* **SOP**：

  * 取花生米大小的 **#0 号** 钢丝绒，用 95% 乙醇浸洗 1 分钟，晾干 2 分钟至乙醇彻底挥发（脱除防锈油）。
  * 稍微扯松，用打火机点燃最下端，出现火星后立即伸入纯氧瓶。
* **教学点**：相比于 #0000 的失控，#0 展现了极其优雅的“动力学与热传导平衡”。可引导观察生成的黑色

  ```rendered
  Fe3O4
  ```

  熔融小球，探讨高温下的相稳定性和表面张力。

### 实验三：自放热稀释与氢气制取 (

```rendered
Zn/Fe+HCl
```

)

* **所需材料**：电池拆出的锌皮，或者脱脂后的 #0 号钢丝绒、10M Muriatic Acid。
* **SOP (自发热 Hack)**：

  * 在烧杯中先加 2 份水，再缓缓倒入 1 份 10M 浓盐酸。
  * 利用强烈的稀释热（Heat of Dilution），溶液自动升温至 40°C - 50°C，浓度降为极度安全的 \~3.3M。
  * 投入锌皮或脱脂 #0 钢丝绒，热酸瞬间浸润，平稳、高速地产出大量氢气。
* **教学点**：Arrhenius 方程的直观展现（温度对反应速率的指数级提升），以及铁与酸反应生成浅绿色

  ```rendered
  Fe2+
  ```

  （而非

  ```rendered
  Fe3+
  ```

  ）的非氧化性环境。

### 实验四：惰性阳极与水电解 (

```rendered
2H2O→2H2+O2
```

)

* **所需材料**：4.5V 电源、纯碱 (

  ```rendered
  Na2CO3
  ```

  ) 水溶液作为电解质。
* **SOP**：

  * **阳极（正极）**：必须夹住电池拆出的**石墨碳棒**（惰性电极）。
  * **阴极（负极）**：可用任何金属线（或另一根碳棒）。
* **教学点**：如果阳极用不锈钢，演示其发生的“过钝化溶解”；换用石墨后，演示水的标准电解析出氧气。展示竞争反应中的电极电势差。

### 实验五：微型窑炉煅烧与苛化法制强碱（顶级综合实验）

* **化学原理**：

  * ```rendered
    CaCO3900∘CCaO+CO2↑
    ```
  * ```rendered
    CaO+H2O→Ca(OH)2
    ```
  * ```rendered
    Ca(OH)2+Na2CO3→CaCO3↓+2NaOH
    ```
* **设备与材料**：丁烷喷枪、铁架台、大小两个瓷坩埚、泥三角、鸡蛋壳粉末、纯碱溶液。
* **SOP**：

  * **敞口灰化**：少量蛋壳粉末放入大坩埚，无盖喷火，烧尽黑炭有机质。
  * **穹顶煅烧**：将小号坩埚**倒扣**在大坩埚上（留极小缝隙排

    ```rendered
    CO2
    ```

    ），形成反射穹顶。猛火烧 10-15 分钟。
  * **苛化水解**：冷却后得极白

    ```rendered
    CaO
    ```

    ，加水生成浑浊石灰乳。加入纯碱溶液搅拌，过滤掉生成的白色

    ```rendered
    CaCO3
    ```

    沉淀，得到**自制 NaOH 溶液**。
* **教学点**：用倒扣坩埚讲解热辐射穹顶效应（Radiation Dome）与勒夏特列原理的排气促反应。用白醋和酚酞去滴定最后的滤液，反向计算出自制 NaOH 的摩尔浓度。

### 实验六：大分子降解（下水道的生化化学）

* **所需材料**：100% Lye 固体配制的 5M 高浓热 NaOH 溶液（分为三杯）。
* **SOP**：

  * **杯 1（加头发）**：等待 20 分钟，观察角蛋白二硫键断裂，头发液化成糊状。
  * **杯 2（加动物脂肪）**：剧烈搅拌冷却，观察甘油三酯皂化生成的漂浮肥皂（脂肪酸钠）。
  * **杯 3（加卫生纸）**：观察

    ```rendered
    β
    ```
    -1,4 糖苷键的耐碱性，纸张不溶解，但由于氢键破坏发生极致溶胀（Mercerization）。
* **教学点**：将有机大分子结构与极端的

  ```rendered
  pH
  ```
  /热力学环境结合，这是 AP 化学迈向大学生物化学的最佳先导课。
