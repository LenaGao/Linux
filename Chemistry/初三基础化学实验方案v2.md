## 一、能力边界（本版重大修正）

### 1.1 蛋壳煅烧：钳夹直烧法

**上一版建议用坩埚 + 保温罩，需 15–25 分钟。经重新评估，改为钳夹直烧，1–3 分钟即可。**

原因是热负载差异：

| 方式 | 热负载 | 达到 825°C 时间 |
| :--- | :---: | :---: |
| 坩埚（15 g 瓷）+ 保温 | 坩埚本身吃掉 10.5 kJ | 15–25 分钟 |
| **钳子直夹薄片** | 几乎为零 | **1–3 分钟** |

蛋壳仅 0.3–0.4 mm 厚，热容极小。薄片四面被火焰包围，对流+辐射同时加热，且分解产生的 CO₂ 直接逸散，平衡一路右移。

**操作要点：**

| 环节 | 要求 |
| :--- | :---: |
| 火焰位置 | **蓝色内锥尖端上方 1–2 cm**（最热区，约 1200–1300°C），不要用黄色外焰 |
| 片子大小 | 指甲盖大小（约 1 cm），太大则中心受热不足 |
| 钳口散热 | 夹住边缘一角，中途换位置再烧几十秒；或用不锈钢网勺批量烧 |
| 预处理 | 清水搓洗去内膜、彻底晾干（湿蛋壳会爆裂弹射） |

**判断标准（看现象，不看时间）：** 冷却后取一小粒滴水 → 明显放热、嘶声、开裂粉化 = 成功。或加水测 pH ≈ 12.4（未烧透只有 9 左右）。

**分工原则：**

| 目的 | 方式 | 原因 |
| :--- | :---: | :---: |
| 快速演示、制石灰水 | 钳子直夹 | 1–3 分钟出结果 |
| 定量测失重率 44% | 坩埚 | 必须能称重 |
| 批量制 CaO 做 NaOH | 网勺 | 一片片夹太慢 |

⚠️ 蛋壳未干透会爆裂弹射，务必戴护目镜，侧向 30 cm 外观察。

### 1.2 电解装置：镍电极无短板

镍是工业碱性电解槽（AWE）的标准材料，两极均稳定：

| 特性 | 表现 |
| :--- | :---: |
| 碱性稳定性 | 极好，无铬溶出、溶液不变黄 |
| 析氧过电位 | 低于不锈钢，同电压下电流更大 |
| 析氢活性 | 优秀 |
| 溶液污染 | 无，学生可安全接触 |

**唯一禁忌：氯离子。** 食盐水电解会击穿钝化膜。氯碱演示必须**改用石墨棒作阳极**（拆废旧碳性电池即得）。

**产气速率（法拉第定律）：**

| 电流 | H₂ 速率 | O₂ 速率 | 装满 250 mL O₂ |
| :--- | :---: | :---: | :---: |
| 1 A | 209 mL/h | 105 mL/h | 72 分钟 |
| 2 A | 418 mL/h | 209 mL/h | 36 分钟 |
| 5 A | 2.1 L/h | 1.05 L/h | **14 分钟** |

**提升电流的手段：** 用自制 NaOH 作电解质（电导率是小苏打的 4–6 倍，工业浓度 25–30%）、加大电极浸入面积、电压控制在 2–3 V 多组并联（勿单池高压，多余电压全变热）。

## 二、零采购实验清单

### 2.1 启普发生器制 CO₂

$$\text{CaCO}_3 + 2\text{CH}_3\text{COOH} \rightarrow \text{Ca(CH}_3\text{COO)}_2 + \text{H}_2\text{O} + \text{CO}_2\uparrow$$

食醋 5%（0.83 mol/L），250 mL 理论产 2.3 L CO₂，可稳定收集 5–6 瓶（每瓶 250 mL 约 3–8 分钟）。

**不要加热**：启普发生器靠液面升降自动控制通断，加热破坏气压平衡且玻璃球易炸裂；醋酸随水蒸气挥发会中和石灰水，干扰检验。

**碎片保持 3–5 mm**：磨粉会堵塞球形漏斗，且无法实现"液面下降即停止"的自动控制。

**可做：** CO₂ 密度大于空气（阶梯蜡烛）、不支持燃烧、溶于水显酸性（pH ≈5.5）、排水法 vs 排空气法对比。

### 2.2 水的组成——2:1 定量验证

$$2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{H}_2\uparrow + \text{O}_2\uparrow$$

**本方案最核心、不可替代的实验。**

建议做法：每 2 分钟同时读两管体积，作 V(H₂)–V(O₂) 图，从**斜率**（应为 2）得结论，而非单点比值。

实测常得 1.9:1——因 O₂ 在水中溶解度是 H₂ 的两倍。**这个偏差不要掩盖**，正好讲系统误差：让学生预测哪管偏少、为什么。正式实验前空跑 5–10 分钟使电解液被 O₂ 饱和，可改善至 1.97:1。

### 2.3 电解质 vs 非电解质

| 溶液 | 导电性 | 教学要点 |
| :--- | :---: | :---: |
| 食盐水 | 强 | 离子化合物，电离 Na⁺/Cl⁻ |
| 味精水 | 强 | 谷氨酸钠也是盐 |
| 小苏打水 | 强 | HCO₃⁻ 导电 |
| 蔗糖水 | 不导电 | 分子化合物，溶而不电离 |
| 95%酒精 | 不导电 | 分子化合物 |
| 蒸馏水 | 极弱 | 对照 |

### 2.4 氯碱工业微型演示（阳极换石墨棒）

| 位置 | 现象 | 反应 |
| :--- | :---: | :---: |
| 阴极 | 气泡，pH 试纸变深蓝 | 2H₂O + 2e⁻ → H₂↑ + 2OH⁻ |
| 阳极 | 气泡，氯气试纸变蓝 | 2Cl⁻ − 2e⁻ → Cl₂↑ |

有 KI-淀粉试纸，**不用鼻子闻就能确证氯气**，让原本危险的演示变得可控。培养皿中两电极间铺几片 pH 试纸，可见碱性区域从阴极向外扩散——离子迁移可视化。

⚠️ 小电流、短时间、开窗，试纸变色即停止。

### 2.5 pH 试纸：把所有材料测一遍

| 物质（水溶液） | 预期 pH | 教学要点 |
| :--- | :---: | :---: |
| 食醋 | 2.4 | 弱酸 |
| 碳酸水（通CO₂） | 5.5 | CO₂ 溶于水生成碳酸 |
| 味精水 | 6.8–7.2 | 略偏中性 |
| 食盐水 | 7.0 | 强酸强碱盐不水解 |
| 蔗糖水 | 7.0 | 非电解质 |
| 小苏打水 | 8.3 | 弱碱性，水解 |
| 碳酸钠水（小苏打加热后） | 11.5 | 明显强于小苏打 |
| 石灰水（蛋壳煅烧后自制） | 12.4 | 强碱 |

**最后两行是关键**——为"加热分解"和"煅烧"提供独立于质量数据的第二重证据。

**缓冲现象演示：** 醋 + 小苏打逐滴中和，每加一次测 pH。pH 先在 4.5 附近赖着不动一大段，然后突然跳升。醋酸/醋酸根是缓冲对，同理小苏打/碳酸钠也是——**这就是血液维持 pH 7.4 的机制**。初三不需要 Henderson-Hasselbalch，但"加了酸 pH 却不怎么变"这个反常足够记一辈子。

### 2.6 坩埚定量实验

**① 小苏打分解（首推）**

$$2\text{NaHCO}_3 \xrightarrow{270°C} \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$$

理论失重率 = (168.02 − 105.99) / 168.02 = **36.9%**

**恒重法：** 空坩埚恒重记 m₀ → 加 2 g 小苏打记 m₁ → 加热至无气体逸出、冷却、称 m₂ → 再加热 10 分钟、冷却、再称，直到两次差 < 0.02 g。

误差 1–2% 内容易达到。**三重证据链**：质量数据 + pH 升高（8.3→11.5）+ 导管通石灰水变浑浊。

**② 蛋壳煅烧定量版**

理论失重 44.0%，**实测偏高至 46–48%**——蛋壳含约 3.5% 有机基质（壳膜蛋白）一并烧掉。这个偏差正好讲**样品纯度与系统误差**：让学生先用醋酸预处理去膜再测一次，对比结果。

**③ 有盖 vs 无盖：干馏原理**

| 条件 | 现象 | 原理 |
| :--- | :---: | :---: |
| 盖紧加热蔗糖 | 熔化→焦糖→黑色多孔炭，残留多 | 缺氧热解，碳留下 |
| 敞口猛烧 | 冒烟起火，残渣极少 | 充分燃烧，C→CO₂ 逸散 |

这就是**木炭烧制原理**，也解释了"为什么烤糊的面包是黑的"。

**④ 灰分测定**

菜叶或蛋壳膜灼烧至白色灰烬恒重，算灰分百分比。食品与生物样品分析的标准操作，引出**有机物 vs 无机物**的分野。

### 2.7 自制氢氧化钠——苛化法（皇冠实验）

$$\text{Ca(OH)}_2 + \text{Na}_2\text{CO}_3 \rightarrow \text{CaCO}_3\downarrow + 2\text{NaOH}$$

驱动力是溶解度差异：

| 物质 | Ksp | 溶解度 |
| :--- | :---: | :---: |
| Ca(OH)₂ | 5.5×10⁻⁶ | 1.7 g/L |
| CaCO₃ | 3.3×10⁻⁹ | 0.013 g/L |

CaCO₃ 溶解度小两个数量级，沉淀把反应强行拉到右边。

**完整路径（原料全部自制）：**

```
蛋壳 CaCO₃ ──钳夹煅烧──> CaO ──加水──> Ca(OH)₂ ┐
                                                ├──> NaOH + CaCO₃↓
小苏打 NaHCO₃ ──坩埚加热──> Na₂CO₃ ─────────────┘        ↓
                                                  CaCO₃ 回炉，循环
```

**配方（制 100 mL 约 0.5 M NaOH）：**

| 步骤 | 用量 | 要点 |
| :--- | :---: | :---: |
| 蛋壳煅烧 | 2.5 g CaCO₃ | 网勺批量烧，见 1.1 |
| 消化 | 得 1.4 g CaO | 少量水成糊状石灰乳 |
| 小苏打分解 | 4.2 g → 2.65 g Na₂CO₃ | 恒重法 |
| 配液 | 溶于 100 mL 水 | 完全溶解 |
| 苛化 | 混合 | 60–80°C 水浴，搅拌 30 min |
| 分离 | 过滤 | 滤液即 NaOH |

**关键：用石灰乳（悬浮液）而非澄清石灰水。** Ca(OH)₂ 溶解度仅 1.7 g/L，澄清液中的量远不够。固体不断溶解补充，反应才能进行到底——这本身就是溶解平衡移动的绝佳案例。

**纯度检验（一滴醋即可）：** 滴食醋于滤液，有气泡说明 Na₂CO₃ 未反应完；无气泡即苛化完全。原理：NaOH 遇酸只中和不产气，Na₂CO₃ 遇酸放 CO₂。

**一个漂亮的细节：** 学生必然问"剩余 Ca(OH)₂ 会不会污染产物"。算给他看：当 NaOH 达 0.5 M 时

$$[\text{Ca}^{2+}] = \frac{5.5\times10^{-6}}{0.5^2} = 2.2\times10^{-5}\ \text{M}$$

**产物自己的 OH⁻ 把杂质压下去了。** 同离子效应不是抽象概念，而是产品纯度的保障——碱越浓，越干净。

**NaOH 解锁：** 皂化反应（食用油 + NaOH + 酒精助溶，做出真肥皂）、中和滴定（配 pH 试纸做滴定曲线）、CO₂ 吸收（塑料瓶变瘪，比石灰水剧烈得多）、氢氧化铁制备（白→灰绿→红棕）、高电导率电解质。

**历史线索：** 这是 Leblanc 制碱法的后半段，后被 Solvay 法取代，再被电解法取代——**而电解法你也有装置**，可直接对比两条工艺路线。

> **注：** 上一版曾建议用"铝箔 + NaOH"制氢作为不买盐酸的替代路线。经评估，该反应涉及两性氢氧化物与配位离子 [Al(OH)₄]⁻，**超出初三知识框架**，学生会卡在"为什么碱也能和金属反应"。已从推荐中移除，改为购买盐酸（见第三节）。

### 2.8 石灰石循环

| 步骤 | 反应 | 现象 |
| :--- | :---: | :---: |
| 煅烧 | CaCO₃ → CaO + CO₂↑ | 疏松发白 |
| 消化 | CaO + H₂O → Ca(OH)₂ | 剧烈放热、开裂、"沸腾" |
| 制石灰水 | 过滤上清 | 澄清透明 |
| 检验 CO₂ | Ca(OH)₂ + CO₂ → CaCO₃↓ | 变浑浊，回到起点 |

从蛋壳出发绕一圈回到碳酸钙，水泥与石灰的工业原理全在其中，**同时解决石灰水试剂来源**。

### 2.9 铁丝在氧气中燃烧

$$3\text{Fe} + 2\text{O}_2 \rightarrow \text{Fe}_3\text{O}_4$$

**用天然气灶预热铁丝替代传统"绑火柴"法**——火柴燃烧会消耗瓶内氧气并引入杂质。

**氧气需求：** 0.10 g 铁丝理论仅需 26 mL O₂，但实际需**约 230 mL 高浓度氧**——铁的燃烧是链式自持反应，需足够高的氧分压，低于约 80% 难以持续。电解 3–5 A 需 14–25 分钟一瓶。

⚠️ 同时产出**双倍体积氢气**（500 mL），必须排放到室外。

| 环节 | 要求 |
| :--- | :---: |
| 铁丝预处理 | 砂纸打磨去油污/镀锌层（**锌沸点 907°C，蒸气有毒**） |
| 形状 | 绕成螺旋（直径 1 cm、3–4 圈），增大受热面、减小散热 |
| 预热判据 | 烧至**明亮橙红**（约 900°C），暗红不够 |
| 时间窗 | 离火后仅 **2–3 秒**，灶与集气瓶并排放置，30 cm 内 |
| 插入方式 | **自上而下缓慢下移**，让铁丝一路都有新鲜氧气 |
| 防炸裂 | **瓶底必铺 1–2 cm 细沙**（熔球超 1500°C） |

### 2.10 其他零采购实验

**铁生锈条件探究**：四支试管对照——① 干燥空气 ② 煮沸冷却水+液封 ③ 自来水+部分露出 ④ 食盐水+部分露出。结论：水与氧气缺一不可，电解质加速。铁丝细，一两天即有明显差异。

**蛋壳半透膜**：整蛋泡醋 2–3 天，壳溶解留下卵壳膜"裸蛋"。浓糖水→皱缩，清水→膨胀。

> **教学彩蛋**：同时开两组——A组整蛋泡醋（半透膜），B组碎壳进启普发生器（制CO₂）。第三天让学生解释：同样的醋和蛋壳，为什么一个还在慢慢冒泡、一个早就产完气了？**表面积对反应速率的影响**，用两个正在进行的实验讲，胜过任何板书。

**分子间有间隙**：95%酒精 50 mL + 水 50 mL → 约 96–97 mL。用细颈容量瓶或长玻璃管效果更明显。

**三种白色粉末鉴别**：

| 方法 | 食盐 | 蔗糖 | 味精 |
| :--- | :---: | :---: | :---: |
| 水溶液导电 | 强 | 不导电 | 强 |
| 加热 | 不变，爆裂声 | 熔化→焦糖→炭化 | 焦化，有氨味 |
| pH | 7.0 | 7.0 | 6.8–7.2 |

**溶解度与结晶**：溶解度曲线测定、冰糖晶体培养（过饱和溶液挂线，一周长出大晶体）、粗盐提纯。

**焰色反应**：铁丝蘸食盐水灼烧 → 明亮黄色（Na）。

## 三、买一样试剂：稀盐酸

### 3.1 为什么是盐酸而非硫酸铜

上一版推荐硫酸铜，**本版改为盐酸**，理由是教学适配度：

$$\text{Fe} + 2\text{HCl} \rightarrow \text{FeCl}_2 + \text{H}_2\uparrow$$

**金属 + 酸 → 盐 + 氢气**——这就是教材原话，一句话讲完，零认知负担。

而氢气是初三化学的**核心气体之一**（与 O₂、CO₂ 并列），没有它整个"三大气体"体系是残缺的。零采购方案里唯一的制氢路线（铝 + NaOH）超纲，因此盐酸是补齐拼图的那一块。

### 3.2 盐酸解锁的实验

| 实验 | 反应 | 说明 |
| :--- | :---: | :---: |
| **制氢气** | Fe + 2HCl → FeCl₂ + H₂↑ | 启普发生器的经典本职工作 |
| 氢气验纯 | — | 尖锐爆鸣 vs 轻微"噗"声 |
| 氢气还原CuO | H₂ + CuO → Cu + H₂O | 黑色变红色，还原性 |
| 氢气燃烧 | 2H₂ + O₂ → 2H₂O | 干冷烧杯罩火焰，内壁水雾 |
| 快速制CO₂ | CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ | 速率是食醋的 10 倍以上 |
| 中和反应 | HCl + NaOH → NaCl + H₂O | 配自制碱 + pH 试纸做滴定曲线 |
| 金属活动性 | Fe/Al/Cu + HCl 对比 | Cu 不反应，引出活动性顺序 |
| 酸的通性 | 与指示剂、金属、碱、盐反应 | 系统性总结 |

**替代：** Home Science Tools 等科教商店有 500 mL 装稀盐酸（浓度已标注），约 $8–10，省去自行稀释的风险。

**稀释配方：**

| 目标浓度 | 取 20% 浓酸 | 加水至 |
| :--- | :---: | :---: |
| 2 M（约7%） | 300 mL | 1 L |
| 1 M（约3.6%） | 150 mL | 1 L |

## 四、买两样试剂：加硫酸铜

### 4.1 硫酸铜解锁的实验

配合现有的**铁丝**，一样试剂解锁一整章：

| 实验 | 反应 | 价值 |
| :--- | :---: | :---: |
| 铁置换铜 | Fe + CuSO₄ → FeSO₄ + Cu | 置换反应、金属活动性，铁丝表面镀红铜 |
| 电镀铜 | 电解 CuSO₄，铁丝作阴极 | 电解应用 |
| **结晶水测定** | CuSO₄·5H₂O → CuSO₄ + 5H₂O | 理论失水 **36.1%**，学生从数据反推 n=5 |
| 检验水 | 白色无水盐遇水变蓝 | 经典检验方法 |
| 氢氧化铜 | Cu²⁺ + 2NaOH → Cu(OH)₂↓ | 配自制碱，蓝色沉淀→加热变黑 CuO |
| 氢气还原CuO | H₂ + CuO → Cu + H₂O | **与盐酸联动**，闭合还原反应链 |
| 晶体培养 | 重结晶 | 可长出大块蓝晶 |

**注意两样试剂的协同**：CuO 来自 Cu(OH)₂ 加热，H₂ 来自 Fe + HCl。**买两样才能做成氢气还原氧化铜**——初三"还原性"概念的标志性实验。

⚠️ **结晶水实验温度控制**：CuSO₄ 超过 650°C 分解成黑色 CuO，实验就毁了。必须坩埚放石棉网上、**天然气灶调至最小火**、远距离加热，控制在 **250–300°C**。

## 六、安全总则

### 🔴 一级：不可逆伤害

| 项目 | 风险 | 措施 |
| :--- | :---: | :---: |
| **NaOH 溶液** | 对眼睛伤害不可逆 | 护目镜全程不摘；皮肤有滑腻感=正在被溶解，立即流水冲 15 分钟 |
| **氢氧混合气** | H₂:O₂=2:1 正是爆炸威力最强比例，爆炸极限 4–75% | 两极产物**始终分开收集**；点燃前**必须验纯**；装置留排气路径 |
| **CaO 消化** | 剧烈放热飞溅 | 护目镜；绝不用手接触 |
| **硫酸铜** | 口服致死量约 10–20 g，儿童更低 | **必须上锁**；废液不可倒入下水道 |

> 备稀醋在旁**仅用于台面清理**。皮肤沾碱只能用水冲——中和放热会加重损伤。

### 🟠 二级：需严格控制

- **浓盐酸**：开盖有酸雾，户外或强通风处稀释；塑料瓶装，不用金属容器；蒸气腐蚀天平和工具，单独存放；**必须上锁**
- **氯气**：小电流短时间，开窗，试纸变色即停，不可密闭收集
- **坩埚骤冷**：高温坩埚碰冷台面或水会炸裂，须用坩埚钳移至石棉网自然冷却
- **称量前冷却至室温**：热坩埚周围空气对流使读数偏轻（这本身也是可讲的误差来源）
- **铁丝燃烧**：集气瓶底必须有细沙
- **镀锌铁丝**：锌沸点 907°C，预热时挥发，蒸气有毒，须先打磨去除
- **蛋壳爆裂**：未干透会弹射，护目镜 + 侧向观察

### 🟡 三级：常规注意

- 95% 酒精易燃，加热时严禁明火直接对容器，与燃气灶分开放置
- pH 试纸不可测 95% 酒精（非水体系读数无意义）——可借此讲 pH 定义的前提是水溶液

### 废液处理

**硫酸铜废液不可直接排放**（对水生生物剧毒）。处理方法本身就是一个实验：

$$\text{Cu}^{2+} + 2\text{NaOH} \rightarrow \text{Cu(OH)}_2\downarrow \xrightarrow{\Delta} \text{CuO} + \text{H}_2\text{O}$$

加自制 NaOH 沉淀，过滤后固废处理。既处理了废物，又讲了沉淀反应和金属氢氧化物热分解，还呼应了自制的碱。

### 分工建议

初三学生：**NaOH 制备、浓盐酸稀释、硫酸铜称量由教师操作**，学生观察记录；后续应用实验（稀释至 0.1–0.5 M）再让学生动手。

## 七、推荐教学路线

### 主线一：从鸡蛋壳到氢氧化钠（3–4 课时）

```
蛋壳 ──钳夹煅烧──> CaO ──水──> Ca(OH)₂ ┐
                                        ├─苛化─> NaOH ──> 电解 ──> H₂ + O₂
小苏打 ──坩埚加热──> Na₂CO₃ ────────────┘                    ↓
                                                          2:1 定量
```

零采购，从厨房材料到氢氧气体全链自制，副产物 CaCO₃ 回炉再用。**建议让学生画出完整物料流程图**，这是真实工业流程的缩影。

### 主线二：定量化学入门（2 课时）

坩埚 + 恒重法 → 小苏打失重 36.9% → 蛋壳失重 44%（实测偏高，讲纯度误差）→ 硫酸铜结晶水 n=5 反推

从"看现象"到"读数据"的思维跃迁。

### 主线三：三大气体（3 课时）

| 气体 | 制法 | 检验 |
| :--- | :---: | :---: |
| CO₂ | 蛋壳/小苏打 + 醋或盐酸 | 自制石灰水变浑浊 |
| O₂ | 电解 或 双氧水+MnO₂ | 带火星木条复燃、铁丝燃烧 |
| H₂ | Fe + 盐酸 | 验纯、爆鸣、还原 CuO |

### 主线四：电与化学（2 课时）

电解质/非电解质对比 → 水的组成 2:1 → 氯碱工业演示 → 铁的腐蚀可视化 → 电镀铜

### 主线五：金属与酸碱（2 课时）

金属活动性（Fe/Al/Cu + 盐酸）→ 铁置换铜 → 中和滴定曲线 → 酸碱指示剂
