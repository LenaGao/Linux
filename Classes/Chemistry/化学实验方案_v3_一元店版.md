## 二、干电池拆解——本版皇冠

一节 $0.31 的电池同时提供**三种化学品**，这是整个方案里性价比最高的一步。

### 2.1 电池结构与产物

超重型（Heavy Duty）干电池即锌碳电池，锌兼作外壳与负极；MnO₂/碳混合物包裹中心石墨棒，石墨棒作为集流体；电解质为 ZnCl₂（重型）或 NH₄Cl（普通型）。

| 部件 | 化学品 | 用途 |
| :--- | :---: | :---: |
| **外壳** | 金属锌 Zn | 强酸制氢、置换反应、原电池 |
| **黑色糊状物** | MnO₂ + 碳粉 | H₂O₂ 分解催化剂 |
| **中心棒** | 石墨 C | 惰性电极（氯碱、电解） |

⚠️ **必须选"Heavy Duty"或"Super Heavy Duty"（锌碳电池）**，不要买碱性电池（Alkaline）——碱性电池结构完全不同，锌是粉末状且含 KOH 强碱，拆解危险且得不到完整锌壳。

### 2.2 拆解步骤

1. 用钳子剥去外层金属/塑料包皮
2. 用小刀沿顶部密封圈划开，取出中心石墨棒（连带黑色糊状物）
3. 刮下 MnO₂ 糊状物，**保持湿润**
4. 剪开锌壳展平，用清水冲洗、砂纸打磨去残留电解质
5. 石墨棒清水刷洗、晾干

⚠️ **安全要点：**

- **MnO₂ 干粉尘有害，绝不可干磨**。取出时应是湿的，若已干燥先加水润湿再研磨
- 使用**新电池**而非废电池——废电池可能已漏液，且锌壳被腐蚀变薄
- 全程戴手套护目镜，拆解后彻底洗手
- 电解质呈弱酸性（ZnCl₂/NH₄Cl），接触皮肤后冲洗

### 2.3 锌解锁了什么（最重要）

之前的方案只有 Fe、Cu、Al 三种金属，缺了关键的**锌**。补上后金属活动性序列完整：

$$\text{Al} > \text{Zn} > \text{Fe} > (\text{H}) > \text{Cu}$$

| 实验 | 反应 | 教学价值 |
| :--- | :---: | :---: |
| **锌制氢** | Zn + 2HCl → ZnCl₂ + H₂↑ | 比铁快得多，气流稳定，启普发生器的标准配置 |
| **锌铜原电池** | Zn ǀ 稀酸 ǀ Cu | 化学能→电能，**用电池的材料造电池** |
| 锌置换铜 | Zn + CuSO₄ → ZnSO₄ + Cu | 比铁置换更剧烈 |
| 活动性排序 | Al/Zn/Fe/Cu + 稀酸对比 | 一次实验排出四种金属顺序 |
| 锌的两性 | Zn + 2NaOH + 2H₂O → Na₂[Zn(OH)₄] + H₂↑ | 高中内容，可作拓展 |

**为什么锌是制氢的最佳选择：**

| 金属 | 与稀盐酸反应 | 评价 |
| :--- | :---: | :---: |
| Al | 剧烈但有氧化膜钝化，起始慢 | 不稳定 |
| **Zn** | **速率适中稳定，气泡均匀** | ✅ 最佳 |
| Fe | 较慢，溶液显绿色（Fe²⁺）后变黄 | 可用但污染视野 |
| Cu | 不反应 | 对照组 |

### 2.4 MnO₂ 解锁：氧气问题彻底解决

$$2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2\uparrow$$

一元店 3% 双氧水 500 mL ≈ 0.44 mol H₂O₂ → **约 5 L 氧气**，几分钟内放完。

**对比之前的电解制氧：**

| 方案 | 250 mL 氧气耗时 | 成本 |
| :--- | :---: | :---: |
| 电解（3 A） | 24 分钟 | 0，但同时产 500 mL 氢气需排放 |
| **MnO₂ + H₂O₂** | **约 30 秒** | **约 $0.10** |

**催化剂概念的完整演示：**

1. 单独加热 H₂O₂ → 缓慢分解
2. 加入 MnO₂ → 剧烈放氧
3. 反应结束后过滤回收 MnO₂，**称重不变**
4. 回收的 MnO₂ 再次加入新的 H₂O₂ → 依然有效

**第 3、4 步是催化剂定义的直接证明**（改变速率、本身质量和化学性质不变），这个实验用其他材料很难做得这么干净。

### 2.5 石墨棒解锁：氯碱工业

镍电极遇 Cl⁻ 会被击穿，之前的氯碱演示无法进行。石墨棒解决了这个问题：

| 位置 | 电极 | 现象 | 反应 |
| :--- | :---: | :---: | :---: |
| 阳极 | **石墨** | 氯气试纸变蓝 | 2Cl⁻ − 2e⁻ → Cl₂↑ |
| 阴极 | 镍/不锈钢 | pH 试纸变深蓝 | 2H₂O + 2e⁻ → H₂↑ + 2OH⁻ |

⚠️ 小电流、短时间、开窗，试纸变色即停止。

### 2.6 电池本身就是教具

拆解前先做一个演示：**用万用表测电压 1.5 V** → 拆开 → 指出锌壳是负极、MnO₂ 是正极活性物质 → 讲原电池原理。

然后用拆出的材料**重新组装一个原电池**（锌片 + 铜片 + 食盐水/柠檬），点亮 LED 或驱动小电机。

**从"拆解商业电池"到"自制电池"的闭环**，是电化学最好的入门路径。

## 三、1982年后美分硬币——免费的锌铜双金属

美国 1982 年后的 1 美分硬币是**锌芯（97.5%）+ 铜壳（2.5%）**。

### 经典实验：溶解锌芯

1. 用锉刀在硬币边缘锉出一个小缺口（露出锌芯）
2. 浸入稀盐酸数小时
3. 锌溶解产生氢气，**留下完整的铜壳**

$$\text{Zn} + 2\text{HCl} \rightarrow \text{ZnCl}_2 + \text{H}_2\uparrow \quad (\text{Cu 不反应})$$

**教学价值极高**：同一枚硬币上，一种金属溶解、另一种不溶——**金属活动性的直接可视化**，比任何表格都有说服力。

> 拓展：对比 1982 年前的硬币（95% 铜），完全不反应。可顺带讲通货膨胀与材料替代的经济史。

## 四、⚠️ 关键陷阱：洁厕灵不能直接当盐酸用

这是本版最重要的技术警告。

### 4.1 三个问题

**① 必须核对标签——配方已变**

The Works 有多个版本：

| 产品 | 有效成分 | 可用性 |
| :--- | :---: | :---: |
| The Works **Disinfectant** | 盐酸 9.5% | ✅ 可用 |
| The Works **Basic Deodorizing** | 盐酸 9.5% | ✅ 可用 |
| The Works **Classic Clean** | **氨基磺酸**（非盐酸） | ❌ 不是盐酸 |

**买之前看瓶身正面**，必须印有 "Hydrochloric Acid 9.5%" 或类似字样。网购版本与门店版本可能不同。

**② 表面活性剂 → 启普发生器灾难**

洁厕灵含增稠剂和表面活性剂（让液体挂壁）。Zn + HCl 产氢时**泡沫会充满整个球体并顺导管爬出**，气体收集完全失败，还得拆开清洗。

**结论：洁厕灵绝不可用于启普发生器。**

**③ 染料与缓蚀剂**

- 蓝/绿染料干扰 pH 试纸读数和中和滴定终点观察
- 部分配方含缓蚀剂（如 Rodine），设计目的就是**减缓酸对金属的腐蚀**——正好与"金属+酸制氢"的目的相反

### 4.2 分场景使用建议

| 用途 | 洁厕灵可用？ | 说明 |
| :--- | :---: | :---: |
| **蛋壳/小苏打制 CO₂**（烧杯中） | ✅ 可以 | 碳酸盐反应不受缓蚀剂影响，泡沫在敞口容器可接受 |
| **启普发生器制任何气体** | ❌ 禁止 | 泡沫爬管 |
| **金属 + 酸制 H₂** | ⚠️ 先小试 | 若反应明显迟缓即为缓蚀剂作祟 |
| **中和滴定** | ❌ 不推荐 | 染料干扰 + 浓度不精确 |
| **定量实验** | ❌ 禁止 | 浓度未标准化 |

### 4.3 结论

**洁厕灵适合定性演示，不适合定量和启普发生器。**

正式实验仍建议买五金店的 **Muriatic Acid**（$7–10/gal，纯 HCl 无添加剂）。$1.25 的洁厕灵可作为**应急替代**或**"生活中的化学"案例**。

### 4.4 🔴 顺带的安全教育（务必讲给学生）

$$\text{NaClO} + 2\text{HCl} \rightarrow \text{NaCl} + \text{H}_2\text{O} + \text{Cl}_2\uparrow$$

**洁厕灵（酸）+ 漂白水（次氯酸钠）→ 氯气**，这是家庭中最常见的中毒事故之一，每年都有致死案例。

瓶身上 "DO NOT MIX WITH CHLORINE-TYPE BLEACHES" 的警告就是这个原因。**这是最贴近生活的化学安全课**，务必让孩子理解原理而不只是记住"不能混"。

⚠️ 此反应**绝不可实际演示**，只作原理讲解。

## 五、更新后的完整实验体系

### 5.1 三大气体（全部低成本解决）

| 气体 | 最优制法 | 材料成本 | 检验 |
| :--- | :---: | :---: | :---: |
| **O₂** | H₂O₂ + MnO₂（电池） | $1.25 | 带火星木条复燃 |
| **H₂** | Zn（电池壳）+ 稀盐酸 | $1.25 + 酸 | 验纯、爆鸣 |
| **CO₂** | 蛋壳/小苏打 + 醋或酸 | ≈0 | 自制石灰水变浑浊 |

**三种气体的原料成本合计不到 $3**，且氧气和氢气的核心材料来自同一节电池。

### 5.2 金属活动性完整实验

材料：铝箔、锌壳、钢丝棉、铜丝，四种金属 + 稀盐酸

| 金属 | 现象 | 结论 |
| :--- | :---: | :---: |
| Al | 起始慢（氧化膜），后剧烈 | 最活泼，但有钝化 |
| Zn | 稳定持续产气 | 活泼 |
| Fe | 缓慢产气，溶液变浅绿 | 中等 |
| Cu | 无反应 | 氢之后 |

**配合置换反应验证：**

- Zn + CuSO₄ → 锌片表面镀红铜
- Fe + CuSO₄ → 铁丝表面镀红铜（较慢）
- Cu + ZnSO₄ → 无反应（逆向不成立）

### 5.3 电化学完整链条

```
拆电池（1.5 V）→ 认识原电池结构
      ↓
自制锌铜原电池 → 点亮 LED
      ↓
电解水（镍电极）→ H₂:O₂ = 2:1
      ↓
氯碱演示（石墨阳极）→ Cl₂ + NaOH
      ↓
电镀铜（铁丝作阴极）→ 电解的工业应用
```

### 5.4 泻盐（MgSO₄·7H₂O）新增实验

| 实验 | 内容 |
| :--- | :---: |
| **结晶水测定** | 理论失水 51.2%，比硫酸铜的 36.1% 更显著 |
| 硬水与软水 | 泻盐水 + 肥皂 → 浮渣；加洗衣苏打软化 |
| 沉淀反应 | MgSO₄ + NaOH → Mg(OH)₂↓ 白色沉淀 |
| 晶体培养 | 针状晶体，几小时即可长出，比硫酸铜快 |

⚠️ MgSO₄·7H₂O 脱水需 150–200°C（低温脱去 6 分子水），完全脱水需 250°C 以上。天然气灶需小火 + 石棉网控温。

### 5.5 保留的零采购经典实验

以下实验不依赖任何采购，详见第二版文档：

- 蛋壳煅烧 → CaO → 石灰水（**钳夹直烧法，1–3 分钟**）
- 苛化法自制 NaOH（教学叙事价值，日常用瓶装碱）
- 小苏打分解定量（失重 36.9%，恒重法）
- pH 试纸测遍所有材料 + 缓冲现象
- 电解质/非电解质对比
- 铁生锈条件探究
- 蛋壳半透膜、分子间隙、三种白色粉末鉴别
- 蔗糖炭化与干馏（有盖 vs 无盖）

## 七、安全总则（第三版增补）

### 🔴 一级：不可逆伤害或致命

| 项目 | 风险 | 措施 |
| :--- | :---: | :---: |
| **酸 + 漂白水** | 生成 Cl₂，家庭常见致死事故 | **绝不演示**，仅讲原理；洁厕灵与漂白水分开存放 |
| **NaOH（通渠剂）** | 100% 纯碱，对眼不可逆 | 护目镜全程；皮肤滑腻感=正在溶解，立即冲 15 分钟 |
| **氢氧混合气** | 2:1 恰是爆炸最强比例 | 两极产物分开收集；点燃前必须验纯 |
| **MnO₂ 干粉尘** | 吸入有害，神经毒性 | **绝不干磨**，保持湿润操作 |
| **硫酸铜** | 口服致死量 10–20 g | 必须上锁；废液不可入下水道 |

### 🟠 二级：需严格控制

- **电池拆解**：用新电池；戴手套护目镜；电解质弱酸性；锌壳边缘锋利需打磨
- **浓盐酸**：户外稀释；**酸入水，绝不水入酸**；塑料容器；蒸气腐蚀天平工具
- **氯气演示**：小电流短时间，开窗，试纸变色即停
- **坩埚骤冷**：必须自然冷却，勿碰冷台面或水
- **铁丝/钢丝棉燃烧**：集气瓶底必铺细沙
- **镀锌铁丝**：锌沸点 907°C，预热时挥发有毒，须先打磨
- **蛋壳爆裂**：未干透会弹射，护目镜 + 侧向观察

### 🟡 三级：常规注意

- 95% 酒精、异丙醇易燃，与明火分开放置
- pH 试纸不可测非水体系（酒精），可借此讲 pH 定义前提
- 钢丝棉极易燃（比表面积大），远离火源存放

### 废液处理

| 废液 | 处理方法 |
| :--- | :---: |
| 含 Cu²⁺ | 加 NaOH → Cu(OH)₂↓，过滤，固废处理 |
| 含 Zn²⁺ | 同上 → Zn(OH)₂↓ |
| 酸碱废液 | 相互中和至 pH 6–8 后大量水稀释排放 |
| MnO₂ | 回收重复使用（催化剂不消耗） |

## 八、推荐教学路线（第三版）

### 主线一：一节电池的化学（2 课时）★ 新增主打

```
测电压 1.5V → 拆解 → 三种产物
                ↓
    锌 ────> 制氢气、金属活动性、原电池
    MnO₂ ──> 催化 H₂O₂ 制氧、催化剂概念
    石墨 ──> 氯碱电解惰性电极
```

**从一个日常物品出发，展开三条化学主线**——这是本方案叙事性最强的一课。

### 主线二：三大气体（2 课时）

O₂（H₂O₂+MnO₂）→ H₂（Zn+酸）→ CO₂（蛋壳+酸），全部现制现用，交叉检验。

### 主线三：金属家族（2 课时）

Al/Zn/Fe/Cu + 酸 → 活动性排序 → 置换反应验证 → **硬币溶锌实验**收尾

### 主线四：从鸡蛋壳到氢氧化钠（3 课时）

保留第二版内容，作为**工艺流程与循环经济**的教学案例（即使已有瓶装 NaOH）。

### 主线五：定量化学（2 课时）

小苏打失重 36.9% → 泻盐失水 51.2% → 蛋壳失重 44%（讲纯度误差）→ 硫酸铜 n=5 反推

### 主线六：电化学（2 课时）

原电池（自制）→ 电解水 2:1 → 氯碱 → 电镀
